Buat akun aplikasi

PIN dipakai untuk masuk ke aplikasi. Nama dipakai kalau kamu memasang beberapa aplikasi di server yang sama.

Huruf/angka tanpa spasi. Contoh: budi, kantor, pribadi.
Ingat baik-baik PIN ini. Bisa diganti di pengaturan aplikasi.

Tempat penyimpanan data

Data keuangan disimpan di database. Pilih cara penyediaannya.

Masukkan akses admin MySQL (untuk membuat database sekali saja — tidak disimpan).

✅ Docker terdeteksi. Wizard akan membuat 1 container MySQL khusus untuk aplikasi ini. Data tersimpan aman walau container dimatikan.
